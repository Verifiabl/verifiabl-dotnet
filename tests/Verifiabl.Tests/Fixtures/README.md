# Cross-SDK fixtures

These files are generated by the Node SDK ([verifiabl-node](https://github.com/Verifiabl/verifiabl-node)), not by hand or by this repo. The PNG parity fixtures (`node-*.rgba.deflate`, `node-png-meta.json`) come from `scripts/generate-dotnet-png-fixtures.mjs`, and the embedded frame assets they are compared against (`src/Verifiabl/Assets/*.vfr1`) come from `scripts/bake-frames.mjs`. Both must be regenerated together, from the same Node commit, whenever the Node compositor or the badge frame changes — otherwise `NodeSdkParityTests` is asserting parity against a stale raster. The Node repo's frame-asset freshness test catches a frame change that was not re-baked at the source.
